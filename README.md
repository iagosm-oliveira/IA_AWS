# IA_AWS — AWS Academy Generative AI Foundations

Repositório voltado ao registro de anotações, resumos teóricos e resoluções dos laboratórios práticos do curso **AWS Academy Generative AI Foundations**.

---

## 📌 Visão Geral do Projeto
Este repositório organiza o aprendizado em duas frentes:
1. **Conteúdo Teórico:** Módulos oficiais da plataforma AWS Academy.
2. **Laboratórios Práticos:** Exercícios hands-on executados no ambiente isolado da AWS.

## 🧪 Ambiente de Laboratórios (Hands-on Labs)

Os exercícios práticos em aula são desenvolvidos na sala dedicada a **Labs da AWS Academy**:

- **Console AWS:** Acesso gerenciado para provisionamento de recursos em nuvem.
- **Serviços Utilizados:** Amazon Bedrock, Amazon SageMaker, AWS Lambda, Amazon S3.
- **Documentação dos Labs:** Os scripts, instruções e resultados de cada prática ficam salvos na pasta `/src/labs/`.
